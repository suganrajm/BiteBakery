## 🍰 About

Bite Bakery is a responsive, single-page bakery site showcasing cakes and treats, a photo gallery, and direct WhatsApp ordering.

## ✨ What's inside

- 🎂 A colorful menu of cakes, cupcakes, cookies, and more
- 📸 A gallery of bakery creations
- 📝 A custom cake request form for celebration details
- 🎨 Cake flavor, weight, color, cake message, and celebration extras
- 🛒 A simple cart for menu items
- 💬 WhatsApp order links for quick contact
- 📱 Responsive layout for desktop and mobile screens

## 🚀 Run it locally

1. Clone this repository:

   ```bash
   git clone https://github.com/suganrajm/BiteBakery.git
   ```

2. Open the project folder.
3. Open `preview.html` in your browser.

No build tools or package installation are required.

## 🧁 Built with

HTML, CSS, and vanilla JavaScript.
